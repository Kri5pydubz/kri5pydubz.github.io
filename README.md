# Kri5pydubz

Public site for **Kri5pydubz**. Identity is **Kri5pydubz** only.

Static one-pager. No build step. GitHub Pages serves the site root.

**Live:** https://kri5pydubz.github.io/

## Pages

Push to `main` deploys via `.github/workflows/pages.yml` (`actions/checkout`, `actions/upload-pages-artifact` with `path: .`, `actions/deploy-pages`).

Enable GitHub Pages for the repo: **Settings → Pages → GitHub Actions**.

## Local

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server --directory . 8080
```
